All portfolio content — hero text, projects, and contact details — lives in the `CONTENT` object at the top of `src/PortfolioApp.jsx`. To add a new project, push another object into the `projects` array; the card renders automatically.

---

## Running Locally

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
